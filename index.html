Adding it to Gmail

        
      

      
    
        
  1. Hit Copy signature.
    2. 
        
  2. In Gmail, open Settings → See all settings → General and scroll down to Signature.
    3. 
        
  3. Create or select a signature, click into the editor and paste with ⌘V.
    4. 
        
  4. Scroll to the bottom and Save Changes.
    5. 
      

      
Everything is inline-styled and table-based, so it survives Gmail, Outlook and Apple Mail. The logo
